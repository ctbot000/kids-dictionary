# Kids Dictionary · 어린이 영어 사전

An English dictionary for Korean-speaking kids. Every word comes with its
pronunciation, its Korean meaning, an English meaning written in easy words,
example sentences, and a short quiz on the meaning. In the pronunciation, say
the **bold** part loudest.

어린이를 위한 영어 사전이에요. 낱말마다 발음, 한국어 뜻, 쉬운 영어 설명, 예문,
뜻을 확인하는 퀴즈가 있어요. 발음에서 **굵은 글자**는 가장 세게 읽어요.

## Adding a word

1. Copy [TEMPLATE.md](TEMPLATE.md) to `words/<word>.md`. The file name is the
   word in lowercase, with a hyphen for a space: `ice-cream.md`.
2. Fill in every section by the rules in [CLAUDE.md](CLAUDE.md).
3. Add the word to the table above, keeping it in alphabetical order.
